
# Changelog

All notable changes to Whale are documented here.

## [0.1.0] - 2026-11-19

### Added
- Initial Cargo workspace.
- Separate serverd and supervisord applications.
- Initial whale-cli application.
- Basic TCP server implementation.
- TCP connection limits.
- Connection timeout.
- Graceful TCP server shutdown.
- Signal handling.
- Structured logging.
- Initial crate structure.
- Project documentation.

### Not implemented
- HTTP protocol handling.
- TLS.
- IPC.
- Zero Trust enforcement.
- OS-level sandboxing.
- Worker management.
